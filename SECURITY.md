# Security

Please report vulnerabilities privately through GitHub's
[security advisory form](../../security/advisories/new) instead of a public
issue. You'll get a response within a few days.

Tarn has no server and collects nothing. It goes online only when the user
uses a feature that needs it (search, voice, Google Lens, AI Mode,
weather), and asks for optional permissions (`management`, `geolocation`)
only when a feature needs them. What each permission and request is for:
[PRIVACY.md](PRIVACY.md).
Any change that widens that surface gets extra review.
